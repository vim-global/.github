# Vim Global GitHub Profile

This repository contains the public organization profile for [Vim Global](https://github.com/vim-global).

- `profile/README.md` — the English presentation displayed on the organization’s Overview page.
- `profile/assets/` — approved logo variants used by the profile.

This repository contains public presentation materials only. It does not contain application source code, deployment configuration, credentials, or internal architecture documents.

Use approved product names and brand assets. Changes to product availability claims must be verified before publication. Logo variants retain their original artwork; GitHub selects the appropriate variant for the visitor’s theme.
